# Math Ninja — заметки разработчика

## Активные системы
- `game.js` теперь содержит основную игровую логику (режимы, движение врагов, крафт, босс).
- `styles.css` отвечает за визуал, вынесен из `index.html`.
- Крафт работает через два слота и четырёхзначный набор операций. Перенос шурикенов — кликом по слоту и затем по числу.

## Режимы игры
- **Бесконечный**: бесконечные волны базовых и элитных врагов. Цель — держать счёт как можно дольше.
- **Сюжетный**: 15 стандартных врагов + босс с тремя щитами. Каждый щит — отдельный пример.

## Босс
- Босс создаётся через `spawnBossTarget()`. В `answers` хранятся ответы для щитов, в `exprs` — текущие выражения.
- Тело босса живёт до тех пор, пока не разрушены все щиты. Снятие щита уменьшает радиус и подменяет выражение.

## Движение врагов
- Поведение задаётся объектом `behavior` (`sine`, `zigzag`, `drift`, `hover`) и обновляется в `updateTargets`.
- Скорость падения плавно растёт через счётчик спавнов `spawnCounter` и easing.

## Крафт
- Кулдаун общий (`CRAFT_COOLDOWN_MS`). Функция `resolveCraft` допускает деление с округлением до двух знаков.
- В `assignToCraftSlot` сбрасывается текущее выделение, чтобы бросок не использовал уже забранный шурикен.

## Дополнительные числа
- `addRandomShuriken` с вероятностью 18% выдаёт числа 1–20 для крафта, помимо правильных значений и балансных выпадений.
